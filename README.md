# YPWC Publication Site

A web portal for the Young Physicists Writing Committee (YPWC) to publish research articles, editorial reviews, scientific handbooks, and community announcements.

[![Next.js](https://img.shields.io/badge/Next.js-15-black?logo=next.js)](https://nextjs.org/)
[![React](https://img.shields.io/badge/React-19-blue?logo=react)](https://react.dev/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3.4-38B2AC?logo=tailwind-css)](https://tailwindcss.com/)

---

## Features

- **Article & Handbook Indexing**: Categorized repository of student research, physics explainers, and handbook volumes.
- **Dynamic Content Pipelines**: Markdown/MDX content parsing with syntax highlighting and LaTeX math rendering.
- **Modern Responsive Design**: Clean typographic layout optimized for scientific reading across desktop and mobile devices.

---

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **UI & Styling**: React 19, Tailwind CSS
- **Package Manager**: pnpm

---

## Getting Started

### Prerequisites
- Node.js >= 18.18
- pnpm >= 8

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Adel-333/YPWC-Publication-Site.git
   cd YPWC-Publication-Site
   ```

2. Install dependencies:
   ```bash
   pnpm install
   ```

3. Start development server:
   ```bash
   pnpm dev
   ```

4. Build for production:
   ```bash
   pnpm build
   pnpm start
   ```
